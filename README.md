# INDOMIEVERSE
Run: `python server.py` then open http://127.0.0.1:8787  (Python 3.9+, no packages needed)
Admin: `ADMIN_EMAILS=you@mail.com python server.py` (PowerShell: `$env:ADMIN_EMAILS='you@mail.com'; python server.py`)
Admins pick the AI provider in Account: builtin (scripted), lmstudio (local), gemini (API key).
Without the server, index.html still works as a local demo (scripted replies, no accounts).
